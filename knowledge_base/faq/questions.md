# \# Business Stack - Полная документация FinCore

# \## ============================================

# \## 1. ФИНАНСЫ (FINANCE)

# \## ============================================

# 

# \### Что можно делать в Финансах?

# \- Создавать и просматривать проводки

# \- Управлять платежами и операциями

# \- Смотреть план счетов

# \- Формировать журнал операций

# 

# \### Как создать платеж?

# Для создания платежа:

# 1\. Перейдите в Финансы → Платежи

# 2\. Нажмите "Добавить платеж"

# 3\. Укажите: сумму, дату, \*\*партнёра\*\*, назначение

# 4\. Выберите тип: доход или расход

# 5\. Нажмите "Сохранить"

# 

# \*\*AI выполняет сам:\*\* "Создай платёж для ООО Ромашка на 50 000 ₽"

# 

# \### Как посмотреть журнал операций?

# Перейдите в Финансы → Журнал операций. Все проводки отображаются в таблице с фильтрами по дате, счетам и партнёрам.

# 

# \*\*AI выполняет сам:\*\* "Покажи журнал операций за январь"

# 

# \### Как редактировать план счетов?

# Перейдите в Финансы → План счетов. Можно добавлять, редактировать и удалять счета.

#

# \## 2. ОТЧЁТЫ (REPORTS)

# \## ============================================

# 

# \### Какие отчёты доступны?

# \- Оборотно-сальдовая ведомость (ОСВ)

# \- Отчёт о прибылях и убытках

# \- Отчёт о движении денежных средств (ОДДС)

# \- Бухгалтерский баланс

# \- Отчёты по продажам

# \- Отчёты по партнёрам

# 

# \### Как сформировать отчёт?

# 1\. Перейдите в Отчёты

# 2\. Выберите тип отчёта

# 3\. Укажите период (день, неделя, месяц, квартал, год)

# 4\. Нажмите "Сформировать"

# 5\. Отчёт отобразится на экране

# 

# \*\*AI выполняет сам:\*\* "Сформируй ОСВ за 1 квартал"

# 

# \### Как отправить отчёт?

# После формирования отчёта:

# 1\. Нажмите "Отправить"

# 2\. Укажите email получателя

# 3\. Выберите формат (PDF, Excel, CSV)

# 4\. Нажмите "Отправить"

# 

# \*\*AI выполняет сам:\*\* "Отправь отчёт о прибылях и убытках на email partner@example.com"

# 

# \### Как скачать отчёт?

# Нажмите "Скачать" и выберите формат: PDF, Excel или CSV.

# 

# \*\*AI выполняет сам:\*\* "Скачай бухгалтерский баланс в Excel"

# \## 3. АКТЫ СВЕРКИ (RECONCILIATION)

# \## ============================================

# 

# \### Что такое акт сверки?

# Акт сверки — документ, подтверждающий расчёты между вами и партнёром.

# 

# \### Как создать акт сверки?

# 1\. Перейдите в Акты сверки

# 2\. Нажмите "Создать акт"

# 3\. Выберите \*\*партнёра\*\*

# 4\. Укажите период сверки

# 5\. Нажмите "Сформировать"

# 6\. Акт автоматически заполнится данными из транзакций

# 

# \*\*AI выполняет сам:\*\* "Создай акт сверки с ООО Ромашка"

# 

# \### Как отправить акт партнёру?

# 1\. Откройте нужный акт

# 2\. Нажмите "Отправить партнёру"

# 3\. Введите email партнёра

# 4\. Партнёр получит ссылку для подписи

# 

# \*\*AI выполняет сам:\*\* "Отправь акт сверки партнёру на email partner@example.com"

# 

# \### Как подписать акт?

# Акт можно подписать электронной подписью прямо в системе.

# 

# \*\*AI выполняет сам:\*\* "Подпиши акт сверки"

# 

# \### Как скачать акт?

# Нажмите "Скачать PDF" — акт сохранится в формате PDF.

# 

# \*\*AI выполняет сам:\*\* "Скачай акт сверки в PDF"

# \## 4. ЖУРНАЛ (JOURNAL)

# \## ============================================

# 

# \### Что такое журнал?

# Журнал — это список всех бухгалтерских проводок в хронологическом порядке.

# 

# \### Как создать проводку в журнале?

# 1\. Перейдите в Журнал

# 2\. Нажмите "Создать проводку"

# 3\. Укажите: дату, счёт дебета, счёт кредита, сумму, описание

# 4\. Нажмите "Сохранить"

# 

# \*\*AI выполняет сам:\*\* "Создай проводку Дт 51 Кт 62 на сумму 100 000"

# 

# \### Как отредактировать проводку?

# Нажмите на проводку, внесите изменения и сохраните.

# 

# \### Как удалить проводку?

# Нажмите на проводку и выберите "Удалить".

# 

# \### Как импортировать проводки из Excel?

# 1\. Нажмите "Импорт из Excel"

# 2\. Загрузите файл с проводками

# 3\. Проверьте соответствие колонок

# 4\. Нажмите "Импортировать"

# 

# \### Как экспортировать журнал в Excel?

# Нажмите "Экспорт" → выберите формат Excel или CSV.

#

# \## 5. УПРАВЛЕНКА (MANAGEMENT)

# \## ============================================

# 

# \### Что такое управленческий учёт?

# Управленческий учёт — это учёт для внутреннего управления бизнесом с тегами, проектами и бюджетами.

# 

# \### Как создать тег?

# 1\. Перейдите в Управленка → Теги

# 2\. Нажмите "Создать тег"

# 3\. Укажите: название, цвет, тип (проект/отдел/категория)

# 4\. Нажмите "Сохранить"

# 

# \*\*AI выполняет сам:\*\* "Создай тег 'Маркетинг'"

# 

# \### Как назначить тег проводке?

# При создании или редактировании проводки выберите нужный тег.

# 

# \### Как посмотреть отчёт по тегу?

# 1\. Перейдите в Управленка → Отчёты

# 2\. Выберите "По тегам"

# 3\. Укажите период и теги

# 4\. Нажмите "Сформировать"

# 

# \### Как создать бюджет?

# 1\. Перейдите в Управленка → Бюджеты

# 2\. Нажмите "Создать бюджет"

# 3\. Укажите: название, период, сумму

# 4\. Назначьте теги и категории

# 5\. Нажмите "Сохранить"

# 

# \*\*AI выполняет сам:\*\* "Создай бюджет на следующий квартал"

# 

# \### Как сравнить план-факт?

# Перейдите в Управленка → План-факт анализ. Система покажет отклонения бюджета от факта.

# 

# \*\*AI выполняет сам:\*\* "Покажи план-факт по проекту Альфа"

# &#x20;  - Начисление налогов

# 4\. Нажмите "Подтвердить закрытие"

# 

# \*\*AI выполняет сам:\*\* "Закрой месяц"

# 

# \### Что происходит при закрытии?

# \- Формируются заключительные проводки

# \- Создаются отчёты за месяц

# \- Блокируется редактирование прошлого периода

# \### Как отменить закрытие?

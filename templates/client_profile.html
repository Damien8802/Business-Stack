Двухфакторная аутентификация (2FA)

Защитите свой аккаунт с 2FA

Двухфакторная аутентификация добавляет дополнительный уровень безопасности. Даже если злоумышленник узнает ваш пароль, он не сможет войти без кода из вашего телефона.

📱 Как включить 2FA:

  1. Нажмите кнопку "Включить 2FA" ниже
  2. Скачайте приложение Google Authenticator или Microsoft Authenticator
  3. Отсканируйте QR-код или введите секретный ключ вручную
  4. Введите 6-значный код из приложения для подтверждения
  5. ✅ Готово! Ваш аккаунт защищён

❓ Часто задаваемые вопросы:

Что делать, если я потеряю доступ к приложению?

Используйте резервные коды — они отображаются ниже после включения 2FA. Сохраните их в надёжном месте (например, в менеджере паролей). Каждый код можно использовать только один раз.

Можно ли отключить 2FA?

Да. Нажмите кнопку "Отключить 2FA" и введите текущий код из приложения для подтверждения. Рекомендуем держать 2FA включённой для максимальной безопасности.

Какие приложения поддерживаются?

✅ Google Authenticator
✅ Microsoft Authenticator
✅ Authy
✅ LastPass Authenticator
✅ Любое другое приложение, поддерживающее TOTP (RFC 6238)

Важно: Сохраните резервные коды! Без них восстановить доступ будет сложнее.
